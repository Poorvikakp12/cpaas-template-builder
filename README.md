# WhatsApp API Templates Builder

[Live Demo](https://suleman-elahi.github.io/whatsapp_api_templates_builder/)

## 🚧 Work in Progress

This project aims to provide a **visual WhatsApp Message Template builder** for generating WhatsApp API template JSONs easily. You can visually design headers, bodies, footers, buttons, and variables for your WhatsApp message templates, and instantly export the correctly formatted JSON for use with WhatsApp APIs.

---

## Features

- **Visual Template Builder:** Drag-and-drop and input fields for creating WhatsApp message templates.
- **Component Support:** Design headers, bodies, footers, and add interactive buttons.
- **Variable Insertion:** Easily add variables to header/body for dynamic content.
- **Category Selection:** Choose template category (Marketing, Utility, Authentication).
- **Export & Copy:** Export your template to JSON, copy to clipboard, or download directly.
- **Sample Templates:** Load sample templates for quick starting points.
- **Responsive UI:** Built with Tailwind CSS for a modern, responsive experience.

---

## Getting Started

### Run Locally

1. **Clone the repo:**
   ```sh
   git clone https://github.com/Suleman-Elahi/whatsapp_api_templates_builder.git
   cd whatsapp_api_templates_builder
   ```
2. **Open `index.html` in your browser.**
   > No build step required! All logic runs in the browser.

### Or Use Online

Visit the [live demo](https://suleman-elahi.github.io/whatsapp_api_templates_builder/) and start building templates instantly.

---

## Usage

1. **Fill in template name, language, and category.**
2. **Add header, body, and footer text.**
3. **Insert variables and buttons as needed.**
4. **Preview your template live.**
5. **Export, copy, or download the generated JSON.**
